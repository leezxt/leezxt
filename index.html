Featured Backend Platform

NewIdeaCase / 模組化後端與 RAG 平台

使用 Java 21、Spring Boot 4.1 建置模組化單體平台，完成商品目錄、使用者資料與訂單流程；支援 Redis read-through cache、游標分頁、部分更新、樂觀鎖與一致的 RFC Problem Details 錯誤契約。

整合 Spring Security、OIDC／JWT 與 Keycloak，由後端解析 tenant、role 及 route scope；RAG 流程實作具 ACL 過濾的文件匯入、可靠切片、Ollama Embedding／生成與來源引用，避免跨租戶資料洩漏。

以 Docker Compose 建立 MongoDB replica set、Redis、Caddy、Prometheus、Grafana、Loki、Alertmanager、Mailpit 與 Portainer，並開發 ECharts 營運監控 Dashboard；使用 JUnit 5、Testcontainers 及驗收腳本覆蓋 API、資料與平台服務。

目前範圍：本機平台與 RAG adapter 已實作；AWS SDK、正式 AWS 部署及 MongoDB Atlas Vector Search 仍保留為後續整合邊界。

MVP Project

Stock AI System / AI 股市分析系統

以 Java 21、Spring Boot 4.1、PostgreSQL／pgvector 與同源前端建置股市分析 MVP，完成市場搜尋、技術摘要、預測、AI 分析／模型比較／聊天、自選清單、帳號設定、回測及 RAG 文件匯入與檢索。

透過 Docker Compose 啟動 Spring Boot 與 PostgreSQL／pgvector，並保留資料庫不可用時的檔案或記憶體 fallback，支援 OpenAI 及 OpenAI-compatible AI Provider。

Cross-platform Project

Secure Messenger / 端對端加密即時通訊系統

以 Flutter 與 Java 21／Spring Boot 4.1 開發模組化 P2P 通訊系統；已用兩台 Android AVD 驗證註冊、邀請碼、雙向聯絡人、公鑰信任及一對一端對端加密文字訊息。

以 WebRTC DataChannel 傳輸加密訊息、WebSocket 進行 Signaling，並完成 P2P 失敗後的加密 Offline Mailbox fallback、ACK／重試及 STORED → DELIVERED → READ 已讀流程；後端使用 PostgreSQL、Flyway、JWT 與 Docker Compose。

已完成低頻 Presence 與 FCM HTTP v1 worker，並建立 GitHub Actions 與 Firebase Test Lab dry-run Gate；架構同時限制背景 heartbeat，以降低行動裝置資源消耗。

目前狀態：仍為內部 Android Alpha；雙真機、真實 FCM Push、正式簽章、Desktop 資源驗收與 iOS 實機 Gate 尚未完成。
