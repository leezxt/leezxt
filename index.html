Featured Backend Platform

NewIdeaCase / 模組化後端與 RAG 平台

使用 Java 21、Spring Boot 4.1 建置模組化單體平台，完成商品目錄、使用者資料與訂單流程；支援 Redis read-through cache、游標分頁、部分更新、樂觀鎖與一致的 RFC Problem Details 錯誤契約。

整合 Spring Security、OIDC／JWT 與 Keycloak，由後端解析 tenant、role 及 route scope；RAG 流程實作具 ACL 過濾的文件匯入、可靠切片、Ollama Embedding／生成與來源引用，避免跨租戶資料洩漏。

以 Docker Compose 建立 MongoDB replica set、Redis、Caddy、Prometheus、Grafana、Loki、Alertmanager、Mailpit 與 Portainer，並開發 ECharts 營運監控 Dashboard；使用 JUnit 5、Testcontainers 及驗收腳本覆蓋 API、資料與平台服務。

目前範圍：本機平台與 RAG adapter 已實作；AWS SDK、正式 AWS 部署及 MongoDB Atlas Vector Search 仍保留為後續整合邊界。

Cross-platform Project

Secure Messenger / 端對端加密即時通訊系統

以 Flutter 與 Java 21／Spring Boot 4.1 開發模組化 P2P 通訊系統；已用兩台 Android AVD 驗證註冊、邀請碼、雙向聯絡人、公鑰信任及一對一端對端加密文字訊息。

以 WebRTC DataChannel 傳輸加密訊息、WebSocket 進行 Signaling，並完成 P2P 失敗後的加密 Offline Mailbox fallback、ACK／重試及 STORED → DELIVERED → READ 已讀流程；後端使用 PostgreSQL、Flyway、JWT 與 Docker Compose。

已完成低頻 Presence 與 FCM HTTP v1 worker，並建立 GitHub Actions 與 Firebase Test Lab dry-run Gate；架構同時限制背景 heartbeat，以降低行動裝置資源消耗。

目前狀態：仍為內部 Android Alpha；雙真機、真實 FCM Push、正式簽章、Desktop 資源驗收與 iOS 實機 Gate 尚未完成。

自傳 / Autobiography

過去我主要從事服務業，累積了與人溝通、理解需求及處理現場問題的經驗。為了突破原有職涯與薪資發展限制，我開始學習 AI 與後端工程，並從財經法律背景跨入軟體開發。服務業讓我習慣站在使用者角度思考；程式開發則讓我找到把需求轉化為實際產品的方法。目前希望投入 AI 應用、生成式 AI／RAG 系統整合或 Java 後端相關工作。

學習期間，我獨立完成 Stock AI System 與 NewIdeaCase 畢業專案，整合 Java、Spring Boot、資料庫、外部 API、Docker 與 RAG。課程結束後，我持續開發 StockPredictor，串接 FinMind、TWSE／TPEx、Yahoo Finance 等資料來源。開發中最讓我印象深刻的是，系統原本設計了兩週回測功能，但每次重新啟動後，H2 內的歷史資料無法延續，導致我一直看不出策略效果。我花了許多時間檢查資料寫入、查詢及回測流程，最後將主要資料庫遷移至 PostgreSQL 17，並加入 Flyway、HikariCP 與 Testcontainers。這次經驗讓我理解，功能可以執行不代表系統真正可靠，資料是否能保存及結果是否能重現同樣重要。

我也從零開發 Secure Messenger，完成兩台 Android 模擬器間的加密訊息傳送，並將原本需要手動按鍵的同步流程改為依待機時間自動同步。開發時主要使用 Codex，搭配 DeepSeek 協助驗證與除錯；我會閱讀程式、日誌與 AI 的分析流程，再自行確認結果。我希望結合服務業的使用者思維、AI 協作及後端實作能力，成為能獨立完成產品原型並持續改善系統的 AI 應用工程師。

English Version

I previously worked primarily in the service industry, where I developed strong communication skills and learned how to understand customer needs and resolve problems in real-world situations. Seeking greater career growth, I began studying AI and backend engineering and transitioned from a background in financial and economic law into software development. My service experience taught me to think from the user’s perspective, while programming gave me a way to turn those needs into working products. I am currently seeking opportunities in AI application development, generative AI and RAG integration, or Java backend engineering.

During my training, I independently completed Stock AI System and NewIdeaCase, integrating Java, Spring Boot, databases, external APIs, Docker, and RAG. After the course, I continued developing StockPredictor and connected it to data sources such as FinMind, TWSE/TPEx, and Yahoo Finance.

One memorable challenge involved a two-week backtesting feature. Because the system initially used H2, historical data did not persist properly after restarting the application, making it difficult to evaluate the strategy. I spent considerable time examining the data-writing, querying, and backtesting processes. I eventually migrated the primary database to PostgreSQL 17 and introduced Flyway, HikariCP, and Testcontainers. This experience taught me that a feature that runs is not necessarily reliable—data persistence and reproducible results are equally important.

I also built Secure Messenger from scratch, successfully sending encrypted messages between two Android emulators and improving the original manual synchronization process by introducing automatic synchronization based on idle time.

I primarily use Codex for development and DeepSeek for additional verification and debugging. Instead of accepting AI-generated answers without question, I examine the code, logs, and reasoning process before validating the results myself. My goal is to combine the user-focused mindset I developed in the service industry with AI-assisted development and backend engineering skills, becoming an AI application engineer capable of independently building and continuously improving product prototypes.
